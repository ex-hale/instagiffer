## Code Style

- **No single-letter variable names.** Use descriptive variable names always, For loop counters `i` is OK. But otherwise: `char` not `c`! `letter` not `l`.
- **snake_case for all variable names** — this applies to Python *and* AutoHotkey code! CamelCase ONLY for Classes.
- Follow PEP 8 naming conventions throughout, regardless of language.
